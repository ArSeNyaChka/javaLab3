## обработка исключений, работа с файлами и сериализация

**Терещенко Арсений Александрович КБ-251**

Фигуры сохраняются в текстовом файле построчно в кодировке UTF-8, где каждая строка содержит тип фигуры и её параметры, разделенные пробелом.

## Пример содержимого:
```
Circle 4.2
Rectangle 1.4 8.8
Rectangle 3.9 7.0
Circle 6.7
```
